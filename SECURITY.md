### Supported Versions


We are currently accepting reports of security issues and vulnerabilities related to the current version of the project. This is the latest version available on GitHub.

If you discover any vulnerabilities in the current version, please let us know.

### Reporting a Vulnerability

You can report a security vulnerability through GitHub issues or by using the contact information provided [here](https://github.com/kittyneverdies/KittyNeverDies).
After receiving your report, we can't predict how much time it will take to fix the vulnerability. If your report was not accepted, it's likely that the vulnerability has already been addressed or there is insufficient information available to address it.
