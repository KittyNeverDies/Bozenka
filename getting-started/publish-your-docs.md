# Help in Development

Bozenka is an open-source project licensed under the GPL-V3 license, so you can help us with its development. We'll provide instructions on how to contribute to the project later. For now, you can help us by creating a fork of our [repository](https://github.com/kittyneverdies/bozenka) and submitting a pull request with your changes. We'll review your changes and code before deciding whether to accept them.
